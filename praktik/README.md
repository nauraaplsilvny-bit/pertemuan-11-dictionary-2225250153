## Tujuan
Memodelkan data pendidikan menggunakan dictionary
dan pasangan key-value.

## Struktur Data
Program menggunakan dictionary dengan NIM sebagai
key utama.

Setiap mahasiswa memiliki value berupa dictionary
yang berisi nama, kelas, dan nilai.

## Cara Menjalankan
Jalankan perintah berikut pada terminal:

python praktik/data_mahasiswa.py

## Refleksi
Saya mempelajari bahwa dictionary digunakan
untuk menyimpan data dalam bentuk pasangan
key-value.
